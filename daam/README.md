# DAAM — интернет-магазин (демо-версия)

«Вкусное начинается здесь». Без базы данных и backend: каталог на локальных данных, корзина/избранное в localStorage, заказ — демонстрационный.

## Запуск
Нужен любой статический сервер (ES-модули не работают при открытии файла двойным щелчком):
- VS Code: расширение **Live Server** → правый клик на `index.html` → *Open with Live Server*;
- или `npm run dev` (или `npm start`) — запустит встроенный сервер на http://localhost:5173, ничего устанавливать не нужно;
- проверка слоя данных: `npm test`.
Адреса вида `#/catalog`, `#/product/moloko-2-5` работают на любом сервере без настройки.

## Структура
```
index.html
assets/products/        ← сюда кладите фото <slug>.jpg (иначе — резервная картинка)
src/
  config/               настройки: источник данных, правила доставки, города
  domain/               типы (Product, Category, CartItem, Order, Customer), формат ответов, утилиты
  data/mock/            ДЕМО-каталог: products.js (60 товаров), categories.js (12 категорий)
  data/repositories/    mockRepository.js (сейчас) · apiRepository.js (будущее) · index.js (выбор)
  api/client.js         API-клиент для будущего backend
  storage/storage.js    единственный модуль с localStorage (версии, валидация)
  services/             cartService, favoritesService, orderService
  ui/                   app.js (оболочка), router.js, components/shared.js (ProductCard и др.), pages/*
  styles/main.css       дизайн-система DAAM
tests/smoke.mjs         проверки данных и сервисов
```

## Что работает
Главная (баннер, категории, подборки, преимущества, подписка), каталог с совместными фильтрами (категория, цена, скидка, сортировка), страницы категорий и товаров с уникальными URL, поиск с подсказками, избранное, корзина (количество, удаление, очистка, итоги, доставка), оформление демо-заказа с валидацией и страницей успеха, страницы «О магазине», «Доставка и оплата», «Контакты», «Политика», 404, адаптивная вёрстка с нижней навигацией.

## Где что лежит
- Демо-товары: `src/data/mock/products.js`; категории: `categories.js`.
- Локальное хранение: только `src/storage/storage.js` (ключи `daam:cart`, `daam:favorites`, `daam:orders`, `daam:city`, `daam:subscribers`).

## Переход на backend и БД
1. `src/config/index.js`: `dataSource: 'api'`, `apiBaseUrl`.
2. `src/data/repositories/apiRepository.js` — сверить эндпоинты с реальным API (контракт методов совпадает с mockRepository).
3. `src/services/orderService.js` — при `api` заказ уже уходит через `api.post('/orders')`; добавить авторизацию и серверный пересчёт сумм.
4. Корзина и избранное: заменить хранилище в `cartService`/`favoritesService` на серверное при необходимости. Компоненты UI менять не нужно.

## Важно
- Фото товаров **не включены**: добавьте файлы в `assets/products/`. Пока их нет, показываются иллюстрации-заглушки.
- Цены, наличие, описания, города, контакты и условия доставки — демонстрационные.
- Профиль/вход не реализованы (кнопка показывает уведомление).
- **Про «Astra»:** я не смог однозначно определить, какая именно технология имеется в виду (в среде нет сети и документации), и не придумывал её API. Проект написан на чистом HTML/JS-модулях без сборки; слои `domain/data/services/storage` не зависят от UI-фреймворка и переносятся на выбранный стек без изменений.
